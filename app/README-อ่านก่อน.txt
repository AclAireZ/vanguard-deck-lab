Vanguard D Deck Lab — ตัวเกม (Windows)

วิธีเปิดเกม
1. แตกไฟล์ zip นี้ไว้ที่ไหนก็ได้ (เช่น Documents\VanguardDeckLab)
2. ดับเบิลคลิก "Create Desktop Shortcut.bat" ครั้งเดียว จะได้ไอคอน "Vanguard Deck Lab" บนเดสก์ท็อป
3. ต่อไปเปิดเกมจากไอคอนนั้น (หรือดับเบิลคลิก "Play Vanguard Deck Lab.bat")
   เกมเปิดเป็นหน้าต่างของตัวเอง ไม่มีแถบเบราว์เซอร์ ใช้ Microsoft Edge ที่มีในทุกเครื่อง Windows 10/11 เป็นตัวรัน (ถ้าไม่มี Edge จะใช้ Chrome)

รูปการ์ด
- เกมโหลดรูปการ์ดจากเว็บทางการเองในเครื่องของแต่ละคน ต้องต่ออินเทอร์เน็ต ทั้งสองฝั่งจึงเห็นรูปการ์ดเหมือนกัน
- โฟลเดอร์ game\cards ใช้ใส่รูปสำรองเองได้ (ชื่อไฟล์ตามชื่อการ์ดหรือเลขรูป เช่น dzbt07_016.png)

เล่นออนไลน์กับเพื่อน
1. ทั้งสองคนลงเกมนี้ในเครื่องตัวเอง แล้วเปิดเกม เลือกเมนู 03 LINK FIGHT และเลือกเด็ค
2. คนหนึ่งกด "สร้างห้อง" จะได้รหัส 6 ตัว ส่งให้เพื่อนทางแชต
3. อีกคนพิมพ์รหัสแล้วกด "เข้าห้อง" ไฟท์เริ่มเอง
- ถ้าเชื่อมไม่ได้ ใช้ "วิธีแลกรหัสยาว" ที่อยู่ด้านล่างในหน้าเดียวกัน

หมายเหตุ
- เด็คและการตั้งค่าเก็บไว้ในเครื่องนี้ (โฟลเดอร์ %LOCALAPPDATA%\VanguardDeckLab) อัปเดตเกมเวอร์ชันใหม่ได้โดยแตก zip ใหม่ทับ เด็คยังอยู่
- เด็คที่เคยสร้างในเว็บหรือไฟล์ VanguardDeckLab.html เดิมไม่ได้ย้ายมาเอง
- ห้องด่วนใช้บริการนัดพบฟรีของ PeerJS (0.peerjs.com) เพื่อจับคู่สองเครื่อง ตัวเกมส่งตรงระหว่างสองเครื่อง
- เครื่องมือแฟนเมดสำหรับซ้อมส่วนตัว ไม่ได้เกี่ยวข้องกับ Bushiroad รูปการ์ดเป็นของเจ้าของลิขสิทธิ์และไม่ได้อยู่ในไฟล์เกม
