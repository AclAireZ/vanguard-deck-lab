## How to restore a fresh workspace
1. Stage `Downloads\VanguardDeckLab\vanguard-deck-lab-source.tar.gz`, `Downloads\vg-cards.json`, `Downloads\VanguardDeckLab\jp-cards.json`, `Downloads\VanguardDeckLab\wiki-cards.json` and `Downloads\VanguardDeckLab\wiki-cards2.json` (+ `jp-text.json`, only needed to read Japanese wording when writing `data/jp-manual.txt`) from the owner's PC
   (or read the `dev/` files published with the artifact; `data/raw.json` exists only on the PC as `vg-cards.json`).
2. `mkdir -p /home/claude/vg && tar xzf vanguard-deck-lab-source.tar.gz -C /home/claude/vg && cp vg-cards.json /home/claude/vg/data/raw.json && cp jp-cards.json /home/claude/vg/data/jp.json && cp wiki-cards.json /home/claude/vg/data/wiki.json && cp wiki-cards2.json /home/claude/vg/data/wiki2.json && cp jp-text.json /home/claude/vg/data/jp-text.json`
3. `node tools/mkwiki.mjs && node tools/mkdb.mjs && node tools/mkjp.mjs && node build.mjs`, then run the tests listed below. (`mkdb` needs `data/base-db.json` (in the archive: card facts + family codes) and `data/raw.json`.)
4. Save again with `bash tools/save.sh` → commit `/mnt/user-data/outputs/vgsave/*` to `Downloads\VanguardDeckLab\`.

## Layout
- `src/engine.js` rules engine · `src/cards.js` hand-written cards + shared families · `src/fx.js` compiled-skill runtime + Thai text
- `src/db.js` card list loader + deck rules · `src/bot.js` · `src/ui.js` table UI · `src/builder.js` deck builder · `src/style.css` · `src/index.src.html`
- `src/db.json` generated by `tools/mkdb.mjs` from `data/raw.json` (official card list dump: 5,826 records)
- `tools/skillc.mjs` skill compiler (card wording → structured skills) · `build.mjs` bundles everything into `dist/`
- Tests: `test/rules.mjs` (rule scenarios) · `test/sim.mjs` (bot/random games) · others listed under "Tests"
